# Киби Studio

Локальная мастерская приложений для Киби DS-02: свой ChatGPT, проекты, фото, общий C++ макет и прошивка.

Скопируйте [стартовый промпт](bootstrap-prompt.txt) в локальный проект ChatGPT/Codex с терминалом. [START_HERE.md](START_HERE.md) объясняет проверяемую установку в новую папку. Установщик сам скачает Node, Codex и при необходимости подписанный Chrome. Python, Homebrew, Xcode, Arduino IDE и ESP32 tools устанавливать не нужно.

Войдите только в свой ChatGPT. В локальной Studio аккаунт Киби не нужен: техническая сессия для предпросмотра и сборки создаётся автоматически. Почтовый вход остаётся на сайте для кабинета и серверного ИИ. API-ключ OpenAI локальному чату не нужен.

Проекты, исходники, история, фото и настройки хранятся на Mac. Для предпросмотра и сборки сервер получает снимок исходников и только нужные параметры приложения. Фото отправляются своему ChatGPT только при явной отправке сообщения; в компилятор и экспорт они не входят. Готовая прошивка скачивается обратно, USB работает локально.

«Новый проект» создаёт чистую основу и сохраняет предыдущую работу. «+» прикрепляет фото. «Проект готов» отправляет короткую просьбу создать код и проверить ошибки и управление. «Прошивка» отдельно открывает сборку и установку. Запись на устройство всегда подтверждает пользователь.

[Полный комплект](kibi-studio-local.zip), [контрольные суммы](release.json), [manifest файлов](kibi-studio-local.manifest.json), [закреплённые версии](runtime-lock.json). Код, нейтральный шаблон, SDK, библиотеки и лицензии внутри ZIP. Личные данные и персональные бинарники не распространяются; пользовательский проект не используется как шаблон выпуска.

Проверены изолированный системный PATH на Apple Silicon, настоящий ChatGPT с фото, серверный C++ макет и компиляция без аккаунта Киби. Очищенная macOS, Intel и установка отсутствующего Chrome физически не проверены. Обычный облачный чат без терминала не может установить программу одним текстом.
