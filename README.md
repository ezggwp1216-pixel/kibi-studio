# Киби Studio

Локальная мастерская приложений для **Киби DS-02**: нативный интерактивный экран, собственный ChatGPT/Codex, исходники, компиляция и USB-загрузка.

## Начать с одного промпта

Откройте [стартовый промпт](bootstrap-prompt.txt), скопируйте его в новый **локальный проект ChatGPT/Codex с терминалом и файлами**. Помощник прочитает [START_HERE.md](START_HERE.md), скачает проверенный комплект в новую папку, проверит инструменты и поможет запустить редактор в Chrome.

Обычная облачная вкладка ChatGPT сама не устанавливает программы на компьютер. Этот выпуск — личная локальная версия для macOS. Для чата используется ваш аккаунт ChatGPT/Codex, отдельный OpenAI API-ключ не нужен.

## Что находится в репозитории

- [START_HERE.md](START_HERE.md) — полная инструкция для помощника.
- [bootstrap.py](bootstrap.py) — загрузчик с закреплённым commit SHA, проверкой SHA-256/manifest и безопасной распаковкой без перезаписи.
- [release.json](release.json) — размеры, версия и контрольные суммы.
- [kibi-studio-local.zip](kibi-studio-local.zip) — полный публичный комплект исходников редактора, проекта, точного SDK, библиотек и лицензий.
- [Manifest](kibi-studio-local.manifest.json) и [SHA-256](kibi-studio-local.zip.sha256).

Код редактора находится внутри ZIP, а не в корне этого репозитория. После распаковки README/AGENTS/контракт платы и инструкции доступны в папке редактора. Загрузчик только скачивает и проверяет файлы — не запускает код, авторизацию или прошивку.

## Перед первым запуском

Нужны macOS, Python3, Node>=22.12, Codex с доступом к app-server, Arduino CLI1.5.1 из Arduino IDE, ESP32 core3.3.12/esp-x322601 и Xcode Command Line Tools. Точный SDK Киби IDF5.5.5 и библиотеки уже включены. Помощник проверяет наличие инструментов и объясняет недостающие шаги установки из официальных источников.

Wi-Fi/API вводятся в Настройках только по необходимости приложения. Личная история, настройки, auth, резервные копии и персональные BIN в этом репозитории отсутствуют. Не добавляйте их при сохранении собственных проектов.

Предпросмотр использует общий C++ renderer/state/input, но не эмулирует радио, I2C, микрофон, батарею и питание. Сборка и физическая USB-запись — отдельные явные действия пользователя. Сторонние лицензии сохранены внутри комплекта в resources/licenses и каталогах компонентов.
