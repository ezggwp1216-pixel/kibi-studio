Установи для меня Киби Studio в новую папку по START_HERE.md из публичного репозитория https://github.com/ezggwp1216-pixel/kibi-studio . Работай в локальном Codex с доступом к файлам и терминалу. Если полный commit SHA уже указан мной или ссылкой, сохрани его; иначе один раз получи SHA main через публичный GitHub API и перечитай инструкцию именно из него. Все файлы бери из того же неизменяемого коммита, не разрешай main заново посреди установки. До запуска проверь SHA-256 сохранённого bootstrap.sh по release.json; проверку архива и manifest выполняет штатный bootstrap. Не используй curl | sh и не проси меня вручную скачивать ZIP. Используй полный комплект этой версии с программами, SDK, клиентом Xiaozhi и инструментами серверных модулей; не заменяй его старым overlay. Пусть установщик сам загрузит закреплённые Node/Codex и при необходимости предложит подписанный Chrome. Не ставь вручную Arduino, Python, Homebrew или Xcode. Помоги мне самостоятельно завершить официальный вход ChatGPT и открой локальную Studio. Если локального терминала нет, объясни, как открыть локальный проект Codex и повторить этот промпт.

Не читай auth.json, личные настройки, .studio, другие проекты или персональные прошивки. Пароли, OTP, коды подключения, Wi-Fi и API-ключи я ввожу только в предназначенные закрытые формы. Для чата Studio не нужен API-ключ OpenAI или кабинет Киби. Не перезаписывай существующую Studio, не выбирай USB-порт и не прошивай плату.

После запуска проверь настоящее сообщение в чате Studio и текущий макет. Для проверки данных в чате Studio вызови только kibi_project_context: сведения о плате, SDK и platform.deviceModules.modules приходят в его ответе, отдельного инструмента каталога нет. Доступность, совместимость и добавление Xiaozhi назови по фактическим полям; если данных нет, скажи «неизвестно». Для голоса нужен профиль «Киби с динамиком», но не меняй выбранный профиль и не утверждай, что он выбран, без данных. Не вызывай kibi_enable_module, не изменяй проект, не запускай сборку и не делай запросов провайдерам при проверке запуска. Если сам не можешь отправить проверку в чат Studio, предложи мне вставить текст, а результат оставь непроверенным.

Кабинет и серверные модули проверяй отдельно, только если я попрошу: kibi_account_status, затем при подключённом кабинете kibi_server_modules и kibi_server_guide({topic:"server-modules"}); свои устройства — kibi_account_devices. Если кабинет отключён, нет прав или сервер не поддерживает API, покажи блокер и скажи, что live-возможности не проверены. Это только чтение: не публикуй и не назначай модуль, не вызывай обработчик или провайдера. Для новых прав объясни: в своём кабинете «Подключить Studio», явно разрешить серверные модули, получить новый код и ввести его только в форму «Аккаунт» Studio; старые права не расширяются автоматически.

После проверки спроси, какое приложение я хочу создать. Когда я отдельно попрошу модуль, прочитай его guide, создай публичный пакет v2 и используй kibi_publish_server_module, kibi_device_modules, kibi_bind_server_module и kibi_rollback_server_module для согласованных публикации, назначения, включения, обновления, выключения и отката. Studio сама вычисляет SHA-256. JavaScript модуля без произвольной сети и секретов. Код подключения, токен Studio и ключи серверных интеграций не входят в пакет или прошивку. Приложение использует отдельный токен своей привязанной Киби, который получает и хранит устройство. Публикация и включение сами не создают фоновую задачу: обработчик вызывает приложение. Реальные runtime/media статусы бери из ответа сервера; ошибку вызова показывай на Киби фиксированным кодом с повтором и остановкой. Расписания не готовы. Успешный пакет или сборка не доказывают настоящий YouTube, звук или работу платы. Сборку запускаю я штатной кнопкой после «Проект готов» и проверки текущей версии; USB-установку подтверждаю отдельно.
