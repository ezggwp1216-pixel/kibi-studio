# Запусти Киби Studio одним промптом на Mac

Инструкция для помощника с доступом к локальному терминалу. Обычный облачный чат без локальных инструментов не может устанавливать программы на компьютере: помоги открыть локальный проект ChatGPT/Codex и повторить исходный промпт. Сначала запускаем редактор, приложение пользователь выберет позже.

## Установка на чистый Mac

Достаточно macOS и интернета. **Не устанавливай Python, Node, Homebrew, Xcode, Arduino IDE или ESP32 tools вручную.** Установщик использует штатные `/bin/sh`, `curl`, `tar` и `shasum`, скачивает закреплённые Node 24.22.2 и Codex 0.166.0 в отдельную пользовательскую папку. Если Chrome/Edge отсутствует, устанавливает подписанный Google Chrome в `~/Applications/Kibi Studio` для USB-загрузки. Пароль администратора не нужен. Предусмотри около 2 ГБ свободного места для среды, браузера и исходников.

Публичный источник: https://github.com/ezggwp1216-pixel/kibi-studio. В корне инструкции и проверяемый ZIP, исходники редактора внутри ZIP.

1. Если SHA уже задан пользователем, URL или стартовым промптом, **сохрани его**. Иначе один раз получи текущий SHA `main` через публичный `GET https://api.github.com/repos/ezggwp1216-pixel/kibi-studio/commits/main`. Принимай ровно 40 строчных hex-символов; GitHub-вход не нужен.
2. Перечитай `START_HERE.md` по `https://raw.githubusercontent.com/ezggwp1216-pixel/kibi-studio/<SHA>/START_HERE.md`. Все файлы дальше из того же коммита.
3. Сохрани `release.json` и `bootstrap.sh` из того же префикса в новую временную папку. Сравни SHA-256 установщика (`/usr/bin/shasum -a 256 <файл>`) с полем `bootstrapShellSha256` в release.json. Поле должно содержать 64 строчных hex-символа. При отсутствии/несовпадении остановись. Не используй `curl | sh`.
4. Выбери новую абсолютную папку под существующим рабочим каталогом. Не удаляй и не перезаписывай прежние проекты. Запусти **проверенный сохранённый** файл:

```sh
/bin/sh /абсолютный/путь/bootstrap.sh --commit <SHA> --destination '/абсолютный/путь/KibiStudio-новый-проект'
```

Пути с пробелами цитируй. Установщик проверяет SHA-256 Node, SHA-512 официального Codex, хеши второго этапа/manifest/каждого файла ZIP, пределы размеров, пути и обычный тип файлов. Он отказывается перезаписывать существующую папку. Node/Codex находятся в `~/Library/Application Support/Kibi Studio/runtime`; системные установки не меняются. Повторно открывай проект файлом **«Запустить Киби Studio.command»** в его папке.

Для автоматизированной проверки без входа и запуска доступен `--install-only`. Этот режим устанавливает среду и проект, но не обращается к аккаунту ChatGPT и не запускает сервер.

## Вход и запуск

У Studio отдельный профиль ChatGPT/Codex: `.studio/account`. Установщик сам запустит официальный `codex login`; пользователь завершает вход в браузере. Пароль, OTP, токен и API-ключ в чат не запрашивай. Не открывай и не копируй `auth.json`, не изменяй глобальный профиль Codex. Входить нужно один раз; история Studio хранится отдельно от облачного ChatGPT Project. Это личная локальная интеграция, не публичный сервер авторизации. Официальная инструкция: https://learn.chatgpt.com/docs/auth?surface=cli.

После входа установщик запускает локальную Studio и открывает Chrome/Edge. Сервер слушает `127.0.0.1:4387`. Если порт занят, не останавливай чужой процесс: используй уже работающую нужную Studio либо задай свободный порт через `KIBI_STUDIO_PORT` перед запуском. Оставь процесс работать.

Проверь название проекта, статус подключения ChatGPT, настоящее сообщение в чате, предпросмотр, нажатия/свайпы и кнопку проверки. Не объявляй запуск успешным только по наличию Node. При ошибке сохрани конкретное публичное сообщение и исправь её; не заменяй чат демонстрационными ответами.

## Где компиляция, исходники и USB

Редактор, исходники проекта и история находятся на Mac. **Предпросмотр и прошивка компилируются на сервере Киби** с закреплёнными SDK/библиотеками для Киби DS-02. Локальный C++/ESP32-компилятор не нужен. Studio подключается к серверу автоматически: входить в Киби или регистрироваться для локального редактора не требуется. Пользователь завершает только официальный вход в свой ChatGPT. Аккаунт Киби нужен для функций сайта, а не для запуска локальной Studio.

Wi-Fi/API пользователь заполняет только по необходимости выбранного модуля в «Настройках». Значения не входят в контекст ИИ и публичный экспорт. Для сборки нужные параметры передаются серверу по HTTPS; исходники и персонализированные бинарники обрабатываются как приватные. Сборку пользователь запускает отдельно. USB-соединение, выбор проверенного бинарника и запись подтверждаются в локальном браузере; автоматически не прошивай устройство. Общая симуляция экрана не подтверждает работу радио/питания на физической плате.

После проверки сообщи адрес, папку проекта и спроси, что пользователь хочет создать для Киби.
