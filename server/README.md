# Kibi Server

Свой сервер Киби с веб-панелью: подключайте устройства, принимайте события, передавайте сообщения и настраивайте текстового ИИ и Telegram. Исходники можно менять вместе со своим ИИ-помощником и запускать на своём компьютере или сервере.

**Начните с [START_HERE.md](START_HERE.md)** или передайте своему ИИ один [стартовый промпт](bootstrap-prompt.txt). Код: [Kibi Server в публичном репозитории](https://github.com/ezggwp1216-pixel/kibi-studio/tree/codex/kibi-server/server).

Для автоматического развёртывания нужен ИИ-помощник с доступом к терминалу вашего компьютера или сервера, например Codex. Обычная вкладка чата без такого доступа сможет объяснить шаги, но сама их не выполнит.

| Возможность | Первая версия |
| --- | --- |
| Панель и API | Статус сервера, свои устройства и реальные события |
| Устройства | Отдельный токен, отзыв доступа, события, очередь входящих сообщений и подтверждения |
| Текстовый ИИ | OpenAI Responses API; свой ключ, модель и системная инструкция; отдельный запрос без истории диалога |
| Telegram | Свой бот и чат, включение уведомлений, явная тестовая отправка |
| Голос, аудиопоток, расписания | Запланированы; в этой поставке не подключены |
| Прошивка | Контракт API для разработчика; автоматического изменения, сборки или прошивки платы нет |

ИИ, с которым вы создаёте проект, и ИИ внутри сервера — разные подключения. Для запросов сервера нужен собственный API-ключ OpenAI и доступная модель; API может расходовать ваш платный лимит. Подписка или вход в приложение ИИ сами по себе не настраивают этот сервер. Ключ вводится в панели, а не в чате помощника. `gpt-5-mini` — исходная настройка модели, её можно изменить на доступную вашему API-проекту.

Для автономного приложения сервер необязателен. Редактор и сборка прошивки — отдельный проект [Kibi Studio](https://github.com/ezggwp1216-pixel/kibi-studio). Сам сервер находится в отдельной папке `server/` ветки `codex/kibi-server` общего публичного репозитория. Это самостоятельный комплект; он не требует запуска Studio и не содержит чужих ключей или настроек.

## Быстрый локальный запуск

Нужен Node.js 24 или новее. После получения и проверки исходников:

```sh
npm run init
npm test
npm start
```

Откройте [http://127.0.0.1:4391](http://127.0.0.1:4391). Пароль находится в `.data/admin-password`; безопасный способ посмотреть его только на своём экране описан в [инструкции](START_HERE.md). Установка npm-зависимостей не нужна. `npm run init` не выводит пароль и не перезаписывает существующие данные.

Для сервера используйте [Docker Compose и HTTPS](START_HERE.md#docker-compose). По умолчанию порт доступен только с самого компьютера. Открывать панель в Интернет следует через HTTPS.

## Данные и границы

Один процесс обслуживает встроенную панель и API; `.data` хранится отдельно от кода. Сессии администратора закрыты HttpOnly-cookie; изменения требуют точного Origin и CSRF. Токены устройств хранятся как хеши. Ключи интеграций зашифрованы локальным ключом; резервная копия всего каталога `.data` должна сохранять ключ и зашифрованное состояние вместе. Это шифрование не защищает от человека, получившего доступ ко всему каталогу или работающему серверу.

Хранилище рассчитано на один экземпляр сервера, без общего сетевого диска и параллельных процессов. Это основа для личной системы: нет учётных записей нескольких администраторов, гарантированной доставки событий или бессрочного журнала. Не отправляйте в ИИ/Telegram сведения, которые нельзя передавать этим провайдерам. Внешние запросы возникают при явном тесте, запросе устройства к ИИ или событии с включёнными уведомлениями; открытие панели их не отправляет.

Пределы: 50 устройств, 200 недавних событий, 50 ожидающих сообщений на устройство, JSON до 16 КиБ. Повторы `eventId` подавляются отдельно для каждого устройства в пределах сохраняемого ограниченного журнала; после вытеснения старого события повтор может стать новым. Устройство должно подтверждать полученное сообщение через `/api/device/ack`. Его токен показывается один раз: при утрате удалите устройство и создайте новое.
