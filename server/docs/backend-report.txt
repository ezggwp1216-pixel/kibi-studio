Operational decisions/limits for docs:
- Node24 built-ins only. One process per data directory. CLI default origin
  http://127.0.0.1:4391; password file defaults dataDir/admin-password, configurable
  by KIBI_ADMIN_PASSWORD_FILE. Admin password requires at least12 chars.
- dataDir0700; encryption.key/state.json0600. Back up entire directory. Missing
  encryption key with existing state fails closed. User-created insecure/linked
  private files fail closed rather than repairing another target's permissions.
- Sessions12h, max128; reset after server restart. Rates:10 login/min per socket
  IP,240 admin calls/min/session,120 device calls/min/token; buckets capped1000.
  Reverse-proxy forwarded client headers are deliberately not trusted.
- Maximum64 pending persistence operations and8 simultaneous provider requests;
  overload returns503 server_busy. Telegram overload retains event as failed.
- Deduplication lasts only while the event remains in the global newest200;
  retrying an evicted event ID creates a new event. Queues reject overflow;
  they never discard an unacknowledged message to admit another.
- An authorized provider request already started may finish after key/device
  revocation. Newly queued device calls recheck revocation inside transaction.
- Events are persisted locally before notification. A process crash after an
  actual upstream send but before final delivery persistence can leave local
  status; no automatic retries, exactly-once upstream delivery is not claimed.
- No public VPS, physical board, real Telegram or real OpenAI verification.
  Root owns browser QA, docs integration, publication and deployment claims.
