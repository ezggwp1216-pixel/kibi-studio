# Обновление публичного SDK Киби

Комплект `2026-11-09-r1` согласует подготовку динамика, аппаратные инструкции,
нейтральный шаблон и известные поколения Wi-Fi. Личные проекты, настройки,
история, авторизация и персональные бинарники не читаются и не заменяются.
Закрытый runtime-код Studio не входит в обновление.

Передайте ИИ после обычного проверяемого запуска Studio:

```text
Обнови публичный SDK моей Киби Studio по docs/SDK_UPDATE.md из того же
закреплённого коммита Kibi Server. Прочитай sdk/device/release.json,
скачай указанный архив и проверь SHA-256 до распаковки/запуска.
Используй Node из установленной Studio; Python, Arduino, Homebrew и Xcode
для этого не устанавливай. Studio должна быть закрыта или не занята.
Сначала выполни read-only план update.mjs для выбранной папки Studio.
Не читай .studio, auth.json, настройки, проекты или BIN; managed Node
используй только как исполняемый файл. При известном SDK выполни --apply
с новой резервной папкой вне Studio, затем doctor.mjs. Неизвестный hash
означает остановку с фиксированным кодом, не разрешение обходить проверку.
После успеха открой Studio. Плату не прошивай; спроси, что я хочу создать.
```

Публичный корень:
`https://raw.githubusercontent.com/ezggwp1216-pixel/kibi-studio/codex/kibi-server/server/`.
Для воспроизводимости замените ветку полным выбранным SHA и используйте его
для инструкции, release и архива. Это дополнение к установщику Studio;
аккаунт Киби для локальной среды не требуется.

На чистом Mac bootstrap уже установил Node:
`<Studio>/.studio/runtime-node/bin/node`. Его запуск не означает чтение приватных
данных `.studio`. Разработчик с Node24 в PATH может использовать обычный `node`.

```sh
"<Studio>/.studio/runtime-node/bin/node" "<kit>/update.mjs" --root "<Studio>"
"<Studio>/.studio/runtime-node/bin/node" "<kit>/update.mjs" --root "<Studio>" --apply --backup-dir "<новая отдельная папка>"
"<Studio>/.studio/runtime-node/bin/node" "<kit>/doctor.mjs" "<Studio>"
```

Без `--apply` изменений нет. До первой записи сверяются известный профиль,
payloads и весь публичный template manifest. Изменённый protected-шаблон,
ссылка или неизвестная версия дают отказ. Нельзя подставлять новый hash в профиль.
При сбое записи обновлённые публичные файлы откатываются. Резервная копия и
receipt содержат только публичный SDK; повторное применение идемпотентно.

`installed-reviewed` сохраняет legacy Wi-Fi/HTTPS. `source-connectivity` относится
к отдельному исходному комплекту с новым controller; им не подменяют работающую
установленную базу целиком. Микрофон есть в обоих вариантах платы.

Doctor проверяет профиль, board snapshots, hashes выбранных публичных заголовков,
подготовку динамика, семейство Wi-Fi и нейтральность инструкции. Его
`hardwareVerified:false` остаётся честным: железо и провайдер не проверяются.
Старые проекты не переписываются; новые возможности принимаются штатным процессом
Studio с проверкой совместимости и новым бинарником. Старый PCM/job helper не
становится совместимым с Opus WebSocket от обновления README.
