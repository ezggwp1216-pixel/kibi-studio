# Kibi Server

Исторический план первоначальной поставки. Последующий отдельный этап добавил выключенный по умолчанию голосовой TLS-шлюз; актуальный контракт и ограничения описаны в [docs/VOICE.md](../../VOICE.md). Пункты о запланированном голосе ниже относятся к первоначальному объёму работ.

Самостоятельно разворачиваемый серверный модуль Киби с веб-панелью. Пользователь создаёт систему с помощью своего ИИ: устройство, приложение, нужные серверные функции и понятные проверки. Сервер необязателен для автономных приложений.

Пользователь попросил универсальный модуль для голоса, Telegram, уведомлений и собственных сценариев, сайт по брендбуку, инструкцию для развёртывания с помощью ИИ и публикацию исходников на GitHub. Рабочее название Kibi Server и первый небольшой комплект — решения реализации.

## Подход

Выбран самостоятельный комплект с Node 24 и Docker Compose. Встроенный сайт и API работают одним процессом; хранилище остаётся в отдельном томе. Это позволяет поднять комплект на личном сервере и менять исходники с ИИ. Отдельный сайт только с описанием не даёт работающей серверной основы; привязка к нынешнему VPS не позволяет пользователю развернуть собственную систему.

## Первая версия

- Панель: реальный статус сервера, подключённые устройства, последние события, модули, пошаговая инструкция и копируемый промпт для ИИ.
- Индивидуальные токены устройств; события от устройства и очередь сообщений на устройство с подтверждением.
- Рабочий модуль Telegram: частное сохранение token/chat ID, включение и явный тест отправки. Без автоматической отправки сообщений при открытии сайта.
- ИИ-модуль OpenAI для текстовых запросов: свой API-ключ, выбор доступной модели и системная инструкция для поведения помощника. Явный тест из панели и защищённый запрос с устройства. Голос и память диалога не приписываются текстовому запросу.
- Пример расширения серверного кода, описание контракта модулей и интеграции с прошивкой.
- Голосовой ИИ и расписания показаны как следующие модули с честным статусом. Перенос текущего голосового движка выполняется отдельно; эта версия не выдаёт его за подключённый.
- README, один стартовый промпт, локальный запуск и установка через Docker Compose с постоянным томом и вариантом HTTPS.

## Ограничения

Никаких пользовательских ключей, настроек Studio, персональных бинарников или файлов существующих серверов в комплекте. Существующий VPS и плата этим этапом не меняются. Авторизация администратора обязательна, ключи Telegram шифруются на диске, токены устройств хранятся как хеши; изменения панели защищены от постороннего Origin и CSRF. Пользователь сохраняет ключи в форме, не в чате ИИ.

Внешний вид опирается на существующий мини-брендбук: #202D85, #FA9442, #FAF6EF и локальный Manrope с OFL. Страница адаптируется к узкому экрану; статусы сопровождаются текстом. Никаких вымышленных устройств, онлайн-показателей или работающих интеграций.

## Проверка готовности

Пустая установка запускается по инструкции, вход работает, созданное устройство отправляет событие и получает сообщение, повтор события не создаёт дубликат, отозванный токен не работает, перезапуск сохраняет данные, API не возвращает секреты. Telegram проверяется изолированным транспортом без сообщений посторонним. Сайт проверяется в Chrome на широком и узком экране. Публикация содержит только этот комплект; предыдущая работа над голосом остаётся на паузе.
