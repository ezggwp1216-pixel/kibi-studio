# Подключение Studio к кабинету и публичным ресурсам

Пользователь подтвердил доработку Studio и повтор нового голосового проекта с нуля.
Приложение, ресурсы и подключение создаёт модель в Studio. Внешний оператор даёт
идею, референс и согласует результат; он не пишет код приложения за модель.

Выбран путь одноразового кода кабинета. Вариант передачи пароля или ключа
провайдера модели даёт лишние права; отдельная административная привязка каждого
проекта оператором не воспроизводит пользовательский путь. Регистрация выдаёт
код на10минут, кабинет позволяет перевыпустить его и отозвать подключения.
Отдельная форма Studio обменивает код на ограниченный90-дневный токен.
Устройство проходит независимую привязку и получает собственный токен через poll.

Для существующего личного Xiaozhi pilot владелец явно допускает один кабинет;
Studio выбирает только его реальное устройство. Общий голос не становится
бесплатной неограниченной услугой. Существующие настройки и данные сохраняются.

Модель получает инструменты публичного поиска, чтения референсов, фиксированных
заголовков SDK и импорта ресурсов. Загрузки ограничены HTTPS, публичными адресами,
размером и временем. Данные внешних страниц не становятся инструкциями.
Исполняемые прошивки не устанавливаются; известный публичный BIN используется
только как источник статически проверенных изображений по SHA256. Новые
неизменяемые блоки добавляются в существующее хранилище изображений активного
проекта доверенным кодом Studio; штатная основа сохраняется побайтно.
Неизвестная лицензия показывается честно; исходные bitmap-данные не публикуются
в публичном серверном репозитории.

Закрытые server.mjs/project-store.mjs установленной Studio меняются локально по
отдельному разрешению пользователя. Публикуются только новые общие модули,
публичная документация и изменения публичного серверного проекта.

Приёмка: offline проверки прав/отзыва/сбоев хранения/SSRF/смены проекта;
локальные HTTP и браузерные проверки; обновление сервера без потери данных;
новый проект исключительно через чат Studio. Компиляция не доказывает звук;
загрузка новой прошивки и физический тест — отдельные фактические этапы.
