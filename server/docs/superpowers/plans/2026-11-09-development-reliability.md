# План аудита и исправлений Киби

**Goal:** исправить подтверждённые дефекты и выпустить согласованную основу
инструкций/SDK с проверяемыми границами аппаратной и серверной готовности.
**Architecture:** текущие драйверы/адаптеры, явные владельцы ресурсов и ограниченные
workers; единый версионированный контракт; сбои сохранения не меняют живое состояние.
**Tech stack:** Node24, public C++ SDK ESP32-S3, Arduino ESP32 3.3.12 / ESP-IDF5.5.5.
**Spec:** ../specs/2026-11-09-development-reliability-design.md

## Constraints / review
Без закрытых проектов и секретов; самостоятельный server остаётся независимым.
Агенты не создают других агентов; edits только в назначенных файлах, Git/deploy root.
Проверять сбои диска, разные поколения SDK, cancel/timeout, offline и переполнение,
границы DMA/ACK, сон/пробуждение, реальные/виртуальные показания оборудования.

1. [x] Независимые аудиты public audio, input/power/network и server/SDK.
2. [x] Server agent: src/store.mjs, src/telegram.mjs, sdk/client.mjs и отдельные
   регрессии tests/reliability.test.mjs. TDD для disk rollback, bounded responses,
   SDK roundtrip и отмены тела. API без новых runtime зависимостей.
3. [x] Input agent: исправление и тест остановки/восстановления нового public
   Wi-Fi controller в отдельном reviewable candidate; не установка вслепую.
4. [x] Audio agent: точный аппаратный контракт/нейтральные рецепты в docs/HARDWARE.md,
   sdk/device/contract.json; не менять рабочие драйверы или код частного приложения.
5. [x] Root: согласовать public source/installed аудио и README/metadata/migration
   только allowlisted SDK-файлов; обновить master prompt и entry/bootstrap docs.
6. [x] Root: автоматическая проверка совместимости/пакета и сценариев приложения,
   target compile, локальные/HTTP/браузерные проверки, независимый review.
7. [x] Root: диагностическая проверка физической платы; обязательно вернуть V55
   через проверяемый существующий путь без чтения персонального BIN.
8. [ ] Root: публикация public исходников/пакетов, безопасное серверное обновление,
   журнал фактической готовности и оставшихся ограничений.

## Проверенные результаты

- Оба публичных профиля SDK прошли doctor; runtime/личные проекты не входят в комплект.
- Временная диагностика скомпилирована точным SDK и проверена на физической плате:
  микрофоны, три сигнала, кнопки, тач, дисплей, сон/пробуждение подтверждены человеком.
  Радиосканирование подтвердило приём; это не тест авторизации Wi-Fi.
- V55 возвращена и запись сверена штатным esptool; NVS не стиралась.
- В отдельном приложении Studio обнаружила и исправила гонку audio fence (V56),
  static_assert/native/kibi_check PASS; target build и физическое воспроизведение
  принимаются отдельно. Персональные исходники/бинарники в этот репозиторий не входят.
