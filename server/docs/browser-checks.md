# Проверка панели

8 ноября 2026 года, встроенный просмотрщик Codex. Использовался отдельный локальный экземпляр с искусственными тестовыми данными, без пользовательских API-ключей и подключённой платы.

- Вход, добавление именованного устройства и окно одноразового токена работают.
- Событие из формы сохраняется в ленте. После настоящего перезапуска процесса сохраняются устройство и событие; требуется повторный вход.
- Запрос к ИИ без сохранённого ключа показывает «Сначала сохраните API-ключ OpenAI»; внешнего запроса нет.
- В инструкции кнопка копирования записывает стартовый промпт, интерфейс подтверждает копирование.
- На ширине 320 CSS px устранено переполнение навигации. После исправления ширина документа равна доступной ширине 305 px с учётом скроллбара.
- Стрелки клавиатуры переключают вкладки; Escape закрывает окно создания и возвращает фокус кнопке.
- В журнале браузера при итоговом проходе нет ошибок и предупреждений.

Голос, настоящие запросы OpenAI/Telegram, публичный HTTPS, Docker и физическая плата этим проходом не проверялись. Проверки внешних транспортов в `npm test` используют контролируемые ответы, а не настоящие провайдеры. Проверка интерфейса не заменяет тест со скринридером или на другом браузере.
