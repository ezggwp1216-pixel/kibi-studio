# Проверка основы разработки Киби — 9 ноября 2026

Обновлены публичный SDK, инструкции и самостоятельный сервер. Личные проекты,
ключи и персональные прошивки в этот репозиторий и комплект не включались.

## Что исправлено

- Ошибка записи на диск откатывает живые объекты к последнему сохранённому
  состоянию. Удаление устройства, ACK и асинхронная доставка не оставляют
  несохранённые изменения или оторванные ссылки.
- SDK и Telegram ограничивают размер, количество фрагментов и время чтения;
  освобождают отклонённые и зависшие ответы. Текстовые поля SDK совпадают с API.
- Новый Wi-Fi controller умеет восстановиться после остановки/ошибки драйвера
  с сохранением пауз повторов. Установленная legacy-база не подменяется им.
- Оба известных профиля получили согласованные инструкции подготовки динамика,
  аппаратного запуска, worker/отмены, батареи и подключения сервисов. Нейтральный
  README больше не описывает чужое приложение; лицензия шрифтов сохранена.

В отдельном разговорном приложении Studio воспроизвела гонку окончания звука,
исправила сброс fence после позднего PCM и проверку очереди/STOP. V56 прошла
static_assert/native/kibi_check, серверную целевую сборку и сверку USB-записи
чтением с SHA-256. Принятие её акустики/длинного разговора на плате — отдельный
ручной шаг; успешная сборка или таймер не доказывают физический playout.
Персональный код/бинарник V55/V56 сюда не входит.

## Поставка и ограничения

- [Аппаратный контракт](HARDWARE.md), [сервисы](SERVICES.md),
  [обновление SDK одним заданием ИИ](SDK_UPDATE.md), [контракт API](API.md).
- Support release `2026-11-09-r1`, архив173 975 байт,
  SHA-256 `49e7a53f64df65bdb62c70d32888b0dca68ffc3445924201cfbb884e39cbe1d2`.
- Публичный выпуск GitHub: `4e9af3d526871a06c1de21c8ae5586285ff06c92`.
  Комплект не содержит закрытый runtime Studio и не переписывает старые проекты.
- Голосовой шлюз владельца сохранён в режиме Xiaozhi с TLS; автоматического
  перехода на платный OpenAI нет. Listener/configured не доказывают доступ к облаку.
- Новые кабинеты изолированы. Email пока служит логином без подтверждения и
  восстановления. Плагины валидируются, но их код не исполняется; расписания и
  многопользовательский voice остаются нереализованными. BLE в закреплённом SDK
  не разрешён; ESP32-S3 не поддерживает Classic/SPP/A2DP.

Новая идея проходит отдельные source/host/target/device/provider проверки.
Этот аудит не является обещанием, что любой сгенерированный код сразу стабилен.
