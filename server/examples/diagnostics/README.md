# Временная проверка оборудования

`KibiHardwareDiagnostics.ino` — публичный тест без SSID, пароля, ключей и запросов
провайдерам. Разработчик использует точный SDK Киби: ESP32-S3/16MiB/DIO40/OPI80,
Arduino3.3.12 и ESP-IDF5.5.5 с PM/tickless/IRAM-safe I2S. Неподходящая библиотека
Arduino не исправляется добавлением макроса. Headers сверяются с sealed manifest.

Перед записью проверяют chip/разметку/размер и обеспечивают возврат рабочего
артефакта. NVS/калибровку не стирают. Тест владеет собственной инициализацией;
его прямое радиосканирование не является рецептом для обычного `app_feature.h`.

- Stereo capture читает обе slots через MicrophoneI2s/Lifecycle.
- «+»/BEEP временно включает duplex Session и три тихких сигнала, завершает media
  нулевыми samples и возвращается к stereo capture. Облачных ACK нет.
- «−» возвращает запись; touch показывает координаты. Drag/Cancel не нажимают кнопку.
- SLEEP проверяет LCD sleep, боковые +/− — пробуждение. Это не измерение deep sleep
  MCU или времени работы аккумулятора.
- Wi-Fi показывает число точек/сигнал; авторизацию/IP проверяют отдельно в рабочем
  приложении с настройками пользователя.
- Батарея/зарядка берутся из штатного измеренного snapshot, не из сценария.

UART выводит только `HTEST` с числами. Монитор не сохраняет чужие баннеры, речь
или память. Звук, физические кнопки, касания и пробуждение подтверждает человек.
После теста возвращают приложение и отдельно проверяют его запуск/соединение.
Персональный бинарник приложения не включают в публичный комплект.
