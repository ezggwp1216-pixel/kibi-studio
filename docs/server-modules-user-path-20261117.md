# Серверный модуль Киби: путь пользователя

Состояние на 17 ноября 2026 года: это инструкция к кандидату выпуска.
Публикация полной Studio с модулями на GitHub, адрес работающего runtime и
проверка на физической Киби здесь не подтверждены. Полная поставка пока имеет
`published:false`; ссылку и точный Git-коммит нужно брать из опубликованного
проверенного релиза, когда он появится.

1. **Получите Studio из GitHub.** Откройте
   [публичный репозиторий](https://github.com/ezggwp1216-pixel/kibi-studio)
   по ссылке выбранного полного выпуска с серверными модулями. Попросите
   локального помощника с терминалом установить проверенный комплект по его
   `START_HERE.md` в новую папку. Штатный bootstrap проверяет архив и сам готовит
   среду; вручную ставить Docker, Python или ffmpeg на Mac не нужно. Обычная
   старая поставка Studio новых инструментов не получает от чтения инструкции.
   Существующую совместимую Studio обновляют отдельным проверяемым overlay,
   сохраняя личные проекты; порядок — в
   [инструкции выпуска](../server/docs/SERVER_MODULES_DEPLOY.md#комплекты-studio).
2. **Подключите свой кабинет.** Войдите на выбранный сервер Киби, нажмите
   «Подключить Studio», включите разрешение «Серверные модули», получите новый
   код и вставьте его только в форму «Аккаунт» Studio. Старое подключение
   сохраняет прежние права. Пароль, код, Wi-Fi и API-ключи не отправляйте в чат:
   для них есть закрытые формы. API-ключ для чата Studio не требуется.
3. **Попросите ИИ сделать модуль и приложение.** Например:

   > Создай для моей Киби беззвучный просмотр YouTube по ID видео. Проверь
   > свой кабинет, устройства и доступность исполнителя/видеообработчика.
   > Сделай серверный модуль и экран с подключением, ошибкой, повтором и
   > остановкой. Опубликуй версию и назначь моей Киби. Секреты в код не добавляй;
   > недоступный runtime покажи честно. USB-установку я подтвержу отдельно.

   ИИ читает `kibi_server_guide({topic:"server-modules"})`, проверяет реальные
   возможности через `kibi_server_modules` и список ваших устройств. Пакет
   v2 — публичный JSON. Ни в него, ни в настройки привязки не добавляйте
   секреты. Секреты пользовательских модулей пока не поддержаны.
4. **Опубликуйте и назначьте.** ИИ может сделать это штатными инструментами,
   Studio сама вычислит SHA-256. Вручную откройте «Серверные модули», загрузите
   `.kibiplugin` и нажмите «Опубликовать версию». Выберите свою Киби, модуль,
   версию и публичные настройки; отметьте «Модуль включён для этого устройства»
   и нажмите «Сохранить привязку». Если устройства нет, сначала привяжите его
   по короткому коду через штатную форму. Публикация или назначение ещё не
   запускает обработчик.
5. **Установите приложение и проверьте вызов.** Согласуйте макет, нажмите
   «Проект готов», дождитесь фактической готовности сборки и отдельно
   подтвердите установку по USB. Приложение вызывает серверный модуль своим
   device token; токен Studio в прошивку не попадает. Первый запрос выполните
   явно в приложении. Для YouTube проверьте настоящий кадр и остановку на Киби.

Управление остаётся в «Серверные модули» Studio и разделе «Модули» кабинета:

| Задача | Действие |
| --- | --- |
| Выключить | Снять «Модуль включён для этого устройства» и сохранить привязку |
| Включить | Проверить версию/настройки, поставить флаг и сохранить; ждать запроса приложения |
| Обновить | Опубликовать новую версию, выбрать её для своей Киби и сохранить |
| Откатить | Указать прежнюю ревизию в «Вернуть предыдущую ревизию привязки» и нажать «Восстановить» |

Откат возвращает версию, настройки и состояние включения как новую ревизию;
прошивку платы он не откатывает. При конфликте нажмите «Обновить», проверьте
текущую ревизию и повторите нужное действие.

**Если модуль не работает.** Окно модулей показывает фактическую доступность
«Изолированного исполнителя» и «Видео YouTube», а также ошибки публикации и
привязки. Ошибка запуска приходит приложению Киби как фиксированный `code`
из `/invoke`: например, `plugin_runtime_unavailable`, `plugin_runtime_timeout`,
`plugin_runtime_failed` или `plugin_media_unavailable`. ИИ должен вывести её
понятным текстом и добавить «Повторить»/«Остановить». Сообщите помощнику код,
версию и действие, без ключей и токенов. Истории вызовов в окне модулей нет;
«Диагностика Киби» относится к голосу.

В этом выпуске реализованы запросы к обработчику, очередь уведомлений своей
Киби и беззвучный кадр YouTube. Произвольной сети из JavaScript и расписаний
нет. Полученный кадр — не обещание плавного видео; очередь уведомлений — не
подтверждение показа. Подробности и ограничения:
[SERVER_MODULES.md](../server/docs/SERVER_MODULES.md),
[YouTube](../server/docs/YOUTUBE_MODULE.md).
